QUESTIONS

Frequently Asked Questions

What is UniEasy?

UniEasy is a platform designed to help students find South African universities and make the application process easier.

What does Apply By Myself mean?

Apply By Myself takes you to the relevant university's application website so that you can complete the application yourself.

What does Apply For Me mean?

Apply For Me is a service where a student provides the required information and documents so that UniEasy can assist with the application process.

How much does Apply For Me cost?

The planned service fee is R5 per university application.

Will my application be submitted immediately?

The current UniEasy website is a front-end prototype. A secure backend and application management system still need to be connected before real applications can be submitted through UniEasy.
